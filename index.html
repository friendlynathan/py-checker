                    Cybersecurity Advisory
                    
The Vibe Coding Security Guide: Preventing AI Slopsquatting

                    

                        When developers "vibe code" with tools like Cursor, Copilot, ChatGPT, or Claude, AI models often hallucinate non-existent Python libraries. Attackers aggressively monitor LLM outputs and auto-publish malicious packages to PyPI matching these hallucinated names.
                    

                

            


            
            

                
                
                

                    

                        
                    

                    
What is AI Slopsquatting?

                    

                        Similar to typosquatting, Slopsquatting occurs when threat actors identify packages hallucinated by Large Language Models (LLMs) and register them on PyPI before unsuspecting developers try to run pip install.
                    

                    
    
                        
  • AI generates plausible names like huggingface-utils-v2.
    • 
                        
  • Threat actors register the exact name on PyPI containing malware.
    • 
                        
  • Developer pastes AI code, runs pip install, executing remote code (RCE).
    • 
                    

                


                
                

                    

                        
                    

                    
5 Golden Rules for Safe Vibe Coding

                    
    
                        
  1. Never blind pip install: Always verify unknown modules on PyPI.org or PyGenuine first.
    2. 
                        
  2. Watch out for import vs package name mismatches: Know that import cv2 is pip install opencv-python.
    3. 
                        
  3. Check package age & release count: Hallucinated malware packages are often less than 48 hours old with 1 release.
    4. 
                        
  4. Use isolated virtualenvs: Always run AI code inside Docker or disposable venvs.
    5. 
                        
  5. Audit requirements.txt: Run PyGenuine prior to running pip install -r requirements.txt.
